# CommitStory

Phase 0 foundation for CommitStory built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run typecheck
```

> This repository currently includes only the Phase 0 landing and UI foundations. GitHub API and analysis features are intentionally not implemented yet.
